# OM AI

OM AI is an operations dashboard and monitoring toolkit for retail teams.

| Component | Public source |
| --- | --- |
| Operations dashboard | [React application](apps/operations-dashboard/) |
| Website demo | [Operations and Orchestrator preview](preview/dashboard-export/index.html) |
| Vehicle Traffic | [Windows monitor and dashboard](vehicle-traffic/SETUP.md) |
| Google Sheets and automation | [Apps Script source](apps-script/) |
| Local health and traffic agents | [PC agent](pc-agent/), [network agent](network-agent/), [surveillance](surveillance/) |

The website demo uses sample data. A production deployment requires authorized accounts, a configured backend, and verified data sources. Live camera dashboards run on the store PC or through approved private access.

See [the workspace guide](UNIFIED-WORKSPACE.md) for development commands. Keep deployment credentials, private configurations, hardware inventory, business records, and footage in restricted storage.
